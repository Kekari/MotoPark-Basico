# MotoPark

App sencilla de asistencia al estacionamiento de motos, hecha en Kotlin con Jetpack Compose.

Tiene dos pantallas: Monitoreo y Configuración. Usa distancias de prueba de 10, 28 y 80 cm para mostrar distintos avisos. Los interruptores son de prueba y no controlan hardware ni reproducen sonido real.

Para ejecutarla, abre esta carpeta en Android Studio, espera la sincronización de Gradle y ejecuta `app` en un teléfono o emulador.

El código principal está en `app/src/main/java/cl/motopark/MainActivity.kt`.
